# CARZA website prototype

A clean, responsive front-end prototype for a South African vehicle marketplace.

## Run it
Open `index.html` in a browser, or upload all three files to a GitHub repository and enable **GitHub Pages**.

## Where to edit cars
Open `app.js` and edit the `CARS` array near the top.

Each vehicle has:
- make
- model
- year
- price
- km
- gear
- fuel
- location
- type
- dealer
- phone
- image

## Important
This is a front-end MVP. It does not yet have a real database, dealer login, payments, authentication, admin dashboard, image uploads, real-time stock, or secure server-side lead handling.

Those should be added before using CARZA as a real commercial marketplace.
